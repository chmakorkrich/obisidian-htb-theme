# Obsidian-HTB-Pwnbox-Theme

A sleek Obsidian theme inspired by **Hack The Box Pwnbox**, designed for hackers, pentesters, and cybersecurity learners who want a familiar terminal-style look while taking notes.

## ✨ Features
- Dark, Pwnbox-inspired color palette  
- High contrast for comfortable long note-taking sessions  
- Clean and minimal UI focused on readability  

## 📦 Installation
1. Download or clone this repository
2. Copy the theme folder into your Obsidian vault(/vault/.obsidian/themes/):
3. Change it in Appreance section
